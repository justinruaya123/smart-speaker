# Semifinal findings and retained evidence

The repository-only handoff produced a functioning streaming software candidate and diagnostic package, **not a qualified assistant**. Training quality gates failed and automatic acceptance is disabled. The implementation uses the newly authorized constrained-phoneme approach; it is described explicitly rather than reclassified as a direct finite-head model.

The 12-epoch primary recipe ran seeds 53 and 71. Seed 71 reached 39/64 raw development exactness at epoch 12 but lost one previously correct command, so the strict guard retained epoch 8 at 11/64. A duration-only 36-epoch ablation, frozen before calibration/test, selected seed 71 epoch 18 at 47/64. Later epochs were retained as rejected evidence when they lost protected commands. No additional architecture search or post-test threshold tuning was performed. [Primary history](reports/semifinal-v1/primary-history.json), [ablation history](reports/semifinal-v1/training-history.json), [development selection](reports/semifinal-v1/development-selection.json).

Calibration achieved the observed precision/FAR constraints only at low recall (298/1,635 valid requests). The policy therefore remains disabled. [Calibration lock](reports/semifinal-v1/calibration-before-test.json). Fresh test waveform ranking was 2,752/3,793 valid commands, with 868 unsupported valid requests retained as misses; all 3,993 evaluated inputs appear in [all_commands.csv](reports/semifinal-v1/all_commands.csv). Correct accepted commands, wrong acceptances, valid failures and negatives have separate exhaustive CSVs in the same directory. The accepted CSV is intentionally header-only.

The original `phone_s53` figures remain historical: 645/706 valid synthetic V6 commands, 0/180 external brightness commands, acceptance disabled. The first-layer adaptation trial was rejected for regression. Neither historical checkpoint was recovered or used in this run. The original tracked source and reports are preserved byte-for-byte in [baseline-cd98092.zip](docs/finalization/baseline-cd98092.zip), SHA-256 `9c391b8a00712cf00099c9d27995abd3b8bfa31aa62541123238535678872d40`. The historical installed artifacts and 433 pre-existing untracked files were outside the migration scope.

The useful command-selection guard and source audit helpers moved to `vcm/selection.py` and `vcm/source_audit.py`. Historical notebook modules were extracted byte-for-byte into `vcm/legacy/tinyvcm/` for comparison tests. They are excluded from deployment. `Architecture.ipynb` is now a curated report importing ordinary code; active training cannot overwrite it. Exact cleanup decisions and recovery identities are in [cleanup_manifest.csv](reports/cleanup_manifest.csv).

To inspect the baseline without overwriting active files, extract the baseline ZIP into a new, empty directory, for example `python -m zipfile -e docs/finalization/baseline-cd98092.zip .cache/baseline-recovery`. This restores the original source tree, not absent historical weights.

The optional visualizer exporter now accepts the selected bundle/checkpoint and verifies their ONNX parity. It no longer requires `experiments/vcm_streaming_v3`. Recipe export was tested; browser/WASM interaction was not revalidated because the local WASM compiler/kernel is absent. The visualizer source and C build recipe remain available, excluded from the Pi package.

Remaining research: complete connected numeric/color/name supervision, explicit unsupported command coverage and hard negatives, larger development selection and training-pool speaker CV, independent human confirmation, and measured physical Pi/far-field behavior. Do not trade those missing denominators for a claim based on parser tests or the 94.09% supported-subset raw ranking rate. [MODEL_CARD.md](MODEL_CARD.md) contains the measured limits and per-family counts.

Independent code review found three substantive issues, all addressed before final packaging. Diagnostic publication now refuses any enabled policy. Calibration and deployment share the candidate gate, including finite scores, a non-null command and a strictly positive margin; replaying the stored calibration decisions produced exactly the same selected thresholds and 301/298 emitted/correct counts, without changing the policy or using test results. Future preparations and fitting enforce feature-byte/frontend identities. A separate post-run feature audit checks the original cache against source WAV recomputation without replacing the original protocol. See [review resolution](reports/semifinal-v1/review.json) and [calibration reconciliation](reports/semifinal-v1/calibration-reconciliation.json).
