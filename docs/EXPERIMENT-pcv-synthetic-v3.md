## Diagnosis and bounded change

Two independent fresh loads of the full Parler model returned empty missing/unexpected/mismatched/error reports, but two audio-decoder tensors differed from the checkpoint: `audio_encoder.model.decoder.model.0.weight_g` and `.weight_v` (runtime names end in `parametrizations.weight.original0` and `original1`). All other indexed tensors matched. On an existing training-only Qwen recording encoded and decoded by that codec, replacing only the incorrect weights changed correlation from -0.0184385 to 0.9672935 and SNR from -8.2912 to 11.9129 dB. A second fresh load reproduced the defect with different incorrect weights. These are reconstruction measurements, not a listening test or VCM acceptance score.

The repaired BF16/CUDA generation pilot checked all 944 indexed tensors exactly against checkpoint values cast to BF16, verified the actual tied embedding alias, generated four training phrases, and checked again with zero changed tensors. Its paired control decodes identical generated codes with the two incorrect versus corrected tensors. Native WAVs and receipts are under `.cache/pcv-delivery-v1/export-diagnosis-20261001/verified-codec/`. No transcript model or general speech recognizer was used, and neither spoken-text nor accent correctness is listener-verified. FP32-only generation and codec precision probes did not remove the original feature-distribution problem; the successful repair changes weight loading, not the declared precision.

The versioned workflow replaces every Parler command and wake recording: 16,608 commands plus 96 continuous wake examples. All 16,704 Qwen and 696 Dia recordings remain referenced in place. Original Parler files, the earlier one-record repair, failed graphs, selected weights, training outputs and all historical human studies remain preserved.

The replacement uses the same 2.2B Parler checkpoint, BF16/CUDA, named voices and English accent descriptions, supplied texts, original batch membership/order (including four mixed command/wake batches), temperature 0.9 and 1,400-token cap. Its 4,182 batches restart at the original first-record seed, with the same three bounded attempts. The earlier one-record repair remains evidence; it is not a special seed override in this complete replacement. Original waveform checks apply, plus CTC frame-capacity checks for every command before any output from a batch is saved. No content-based filtering or label adjustment is permitted.

Before generation, after the first generated batch, and at completion, the loader verifies the complete model. Post-generation checks require zero pre-repair differences so a recurrence cannot be hidden by reloading. Unknown weight drift, missing keys, invalid aliases, remapping collisions and nonfinite checkpoint values reject the run. The protocol binds downloaded assets/tokenizers, the actual Parler/Transformers/DAC/audiotools implementations, package versions, parent protocols/sources, prior assembly evidence and all six parent manifests. A single exclusive marker prevents a duplicate generator. Failed or interrupted work must be diagnosed and preserved; there is no automatic restart over partial output.
