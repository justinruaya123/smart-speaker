# AI231 ME2 voice-command dataset

```
dataset/
  train/     manifest.csv  audio/   10,682 clips,  6.4 h
  test/      manifest.csv  audio/    4,418 clips,  2.5 h
  holdout/   manifest.csv  audio/      196 clips,  0.2 h
  numerals/  manifest.csv  audio/   66,390 clips, 21.8 h   number-only clips, separate from the splits
  variations.csv                     the 93 command variations (sheet "Option B")
```

- **Audio:** every file is 16 kHz, mono, 16-bit PCM WAV.
- **Paths:** `file` in each manifest is relative to that split's folder, so the whole `dataset/` folder can be copied anywhere.

## Splits

No speaker or synthetic voice appears in more than one split.

- **holdout:** for the live test on the Raspberry Pi.
  - 2 clips per variation: one real take from speaker 202520785, plus one synthetic voice (`s10` or `s100`). Where he has no take, both clips are synthetic voices.
  - These speakers' other clips are not used anywhere.
- **test:** 30% of all other speakers, chosen by speaker, stratified so test gets its share of each group:
  - ME2 group speakers (201435283);
  - Xela's speakers (S4, S5);
  - Filipino-English and other synthetic voices;
  - each open-source dataset.

  47 clips per variation, plus an out-of-scope class of 47 clips (Filipino speech, near-miss requests, general speech).
- **train:** the other 70% of speakers. 111 clips per variation, plus:
  - one out-of-scope class (`bucket` = `OUT_OF_SCOPE`): 111 sampled clips plus the 90 group recordings relabelled out of scope;
  - group recordings whose slot value is not in the schema.
- **numerals:** not a split; a separate set for the slotted commands' numbers.
  - It is taken out of the pool before the split, so it plays no part in choosing train/test/holdout speakers.
  - It holds every clip that is only a number: MLEnd spoken numerals (32,029) and Speech Commands digits (34,361).
  - None of its speakers is in test or holdout. The `note` column would say "speaker also in test/holdout" if one were.

The sampled out-of-scope clips in every split follow a fixed mix: noise 10%, Filipino speech 30%, near-miss requests 40%, general speech 20%. A kind that runs short hands its share to the others.

Within a variation, real clips come first (group recordings, then open-source non-native English, then native English), up to half; the group's synthetic set fills the rest.

## Manifest columns

| Column | Meaning |
| --- | --- |
| `file` | audio file, relative to the split folder |
| `transcript` | what is said in the clip |
| `command` | one of the 19 schema commands, or `OUT_OF_SCOPE` |
| `variation` | the Option B variation the clip belongs to (93 classes); blank for out of scope, numerals and non-schema slot values |
| `slot_value` | the variation's slot value (e.g. `22 degrees`, `Red`, `6:00 AM`), blank for fixed commands |
| `out_of_scope` | 1 if the clip asks for none of the 19 commands |
| `bucket` | balancing bucket: the variation, `OUT_OF_SCOPE`, `NUMERAL`, or `<COMMAND> (other slot value)` |
| `speaker_id` | speaker or synthetic voice id |
| `source` | dataset the clip came from |
| `is_synthetic` | 1 for the group's synthetic set |
| `accent_group` | Filipino (group), Filipino (open-source), Native English, Other Asian English, Other / non-native, Unknown, Synthetic |
| `numerals` | the numbers spoken in the clip, as digits |
| `duration_s` | length in seconds |
| `transcript_source` | where the transcript comes from: `dataset` (human transcript), `prompt` (text the speaker read), `label` (text given to the TTS, or the MLEnd numeral), `whisper` / `folder_phrase` (202322013's unscripted takes), `silence` |
| `whisper_check` | holdout: `audio covers variation` if whisper hears the same command and slot value; train/test group takes: `match` / `mismatch` / folder check |
| `note` | how the clip was chosen (group recording, open-source, synthetic set, numeral, …) |
| `variation_match` | `exact` if the transcript is the Option B wording, `close <score>` if it is the same command and slot value in other words |
| `original_path` | where the source file is on the build machine |

## Transcript caveats

- `whisper` and `folder_phrase` rows (train only) are not human-checked.
- **Real voices are checked against the audio:** every group recording was transcribed with whisper large-v3-turbo and compared with its label (`whisper_check`, `whisper_transcript`).
  - Audio matches the label: kept.
  - Whisper heard the label's sounds as other words (Filipino accent: "Pause" → "Boss", "Text Jane" → "Thanks, Jane"): kept (`accent mishearing, kept`).
  - Anything else becomes out of scope, and its transcript is what whisper heard: background talk, silence, or a wrong slot value ("Alarm 8:00 AM" heard as "8 pm"). 100 clips. The old label is in the manifest's notes.
- **Synthetic clips are not checked with whisper.**
- 11 train clips are background noise with an empty transcript.

Built by `~/ai231-me2-collated/scripts/` (`build_manifest.py` → `balance_manifest.py --split` → `export_dataset.py`).


`audio` holds the 16 kHz waveform; `file` is the clip's name in the original folder layout.
